# Skills

Subpastas com `SKILL.md` são copiadas pelo `install/` para o destino configurado. A versão do pacote de conteúdo está em `VERSION` na raiz do repositório e deve coincidir com `baladapp_ia_config_version` nos arquivos de `rules/` e `commands/`.
