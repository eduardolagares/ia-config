# Skills

Skills em `skills/eduardolagares/*/SKILL.md` são copiadas pelo `install/` para `{destino}/skills/eduardolagares/` (inclui `escrever-tarefa`, `gerar-plano-de-implementacao`, `monday-task-info`, `revisar-tarefa`, `tdd-doc`, `refatorar-codigo`, etc.).
