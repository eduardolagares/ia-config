# Skills

Subpastas com `SKILL.md` são copiadas pelo `install/` para o destino configurado. A versão do pacote de conteúdo está no arquivo `VERSION` na raiz do repositório e deve coincidir com o atributo `VERSION` no frontmatter dos arquivos de `rules/` e `commands/`.
